# Ken's Linktree - 個人連結樹頁面

## 專案概述

一個現代化的個人連結集合頁面，具備完美的響應式設計和多帳戶 GitHub 選擇器功能。

## ✨ 主要特色

### 🎨 視覺設計

- **完美對齊系統**: 所有圖示和文字實現像素級完美垂直對齊
- **響應式設計**: 支援從桌面到 iPhone SE 等各種螢幕尺寸
- **動態背景**: 高品質影片背景自動循環播放
- **漸層與特效**: 多種顏色主題和漸層效果

### 📱 響應式優化

- **6 個精確斷點**: 桌面、大型平板、小型平板、標準手機、小型手機、超小手機
- **百分比精確計算**: CSS 變數系統確保各螢幕尺寸完美顯示
- **iPhone SE 特殊優化**: 94%寬度實現"快要全寬但不全寬"效果
- **觸控友好**: 適當的按鈕高度和觸控區域

### 🔧 GitHub 多帳戶系統

- **智慧帳戶選擇**: 點擊 GitHub 按鈕展開多個帳戶選項
- **平滑動畫**: 帳戶面板展開/收合動畫效果
- **帳戶資訊**: 顯示帳戶名稱、描述和自定義圖示

## 🚀 技術實作

### CSS 變數系統

採用精確的百分比計算系統，確保跨螢幕一致性：

```css
:root {
  /* 桌面版 */
  --btn-width-desktop: 400px;
  --icon-left-desktop: 160px;
  --text-left-desktop: 195px;

  /* iPhone SE 優化 */
  --btn-width-small-mobile: 94%;
  --icon-left-small-mobile: 12%;
  --text-left-small-mobile: 17%;
}
```

### 響應式斷點

| 螢幕尺寸 | 寬度範圍   | 按鈕寬度 | 設計目標       |
| -------- | ---------- | -------- | -------------- |
| 桌面版   | ≥1367px    | 400px    | 固定寬度居中   |
| 大型平板 | 769-1024px | 88%      | 適度寬度       |
| 小型平板 | 481-768px  | 90%      | 平衡顯示       |
| 標準手機 | 376-480px  | 92%      | 寬屏利用       |
| 小型手機 | 321-375px  | 94%      | iPhone SE 優化 |
| 超小手機 | ≤320px     | 96%      | 最大利用       |

### 完美對齊算法

使用絕對定位和精確邊距實現完美對齊：

```css
.link-btn i {
  position: absolute;
  left: var(--icon-left-mobile); /* 精確百分比定位 */
}

.link-btn span {
  margin-left: var(--text-left-mobile); /* 對應文字邊距 */
}
```

## 🛠️ 使用方式

### 基本部署

1. 下載所有檔案到網頁伺服器
2. 確保影片檔案路徑正確
3. 直接開啟 `index.html`

### 自定義設定

參考 `docs/customization.md` 進行：

- 連結修改
- 顏色主題調整
- 背景影片更換
- GitHub 帳戶設定

### 響應式調整

修改 CSS 變數來調整各螢幕尺寸的顯示效果：

- `--btn-width-*`: 控制按鈕寬度
- `--icon-left-*`: 控制圖示位置
- `--text-left-*`: 控制文字對齊

## 🔧 維護指南

### 新增連結

1. 在 HTML 中加入新的按鈕元素
2. 設定對應的圖示和文字
3. 應用相同的 CSS 類別

### 調整對齊

1. 修改對應的 CSS 變數
2. 測試各個響應式斷點
3. 確認 GitHub 選擇器對齊一致性

### 更新背景影片

1. 將新影片放入 `src/background-media/`
2. 更新 JavaScript 中的影片列表
3. 測試自動播放功能
